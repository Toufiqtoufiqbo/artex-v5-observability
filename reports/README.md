# Reports in this repository

All reports under this directory are preserved from the ARTEX v5 development phases (IX.1 – IX.2.4).

For public release, local filesystem paths and user-home paths were replaced with placeholders:

| Placeholder | Meaning |
|---|---|
| `<WORKSPACE>` | original local workspace root |
| `<REPO_ROOT>` | local checkout of `artex-original` |
| `<GO_BIN>` | local Go toolchain bin directory |
| `<USER_HOME>` | local user home directory |
| `<OPENCODE_SESSION_DIR>` | local agent session/temp directory |

No benchmark run IDs, fingerprints, ground-truth data or measurements were altered — only path strings. No credentials, DSNs, cookies or private evidence bodies appear in these reports or artifacts.
